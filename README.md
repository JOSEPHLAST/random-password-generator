# 🔐 RANDOM PASSWORD GENERATOR    

## **📌 OVERVIEW**  
This is a **Random Password Generator** built using **HTML, CSS, and JavaScript**. It allows users to generate secure passwords with customizable options like **length, uppercase, lowercase, numbers, and special characters**.

## **🚀 FEATURES**  
✅ **Generate Random & Secure Passwords**  
✅ **Customizable Options** – Choose character types (uppercase, numbers, symbols)  
✅ **Copy to Clipboard** – Easily copy the generated password  
✅ **User-Friendly UI** – Simple and responsive design  
✅ **Instant Password Strength Indicator**

## **🚀 INSTALLATION AND SETUP**  
### **1️⃣ Clone the Repository**  
git clone https://github.com/JOSEPHLAST/random-password-generator.git  
cd random-password-generator  

### **2️⃣ Open in Browser**
Simply open the index.html file in your browser to start using the app.   

## **🎮 HOW TO USE**
1️⃣ Select the desired password length. 
2️⃣ Choose character types (uppercase, lowercase, numbers, symbols). 
3️⃣ Click “Generate Password” to create a secure password. 
4️⃣ Click “Copy” to copy the password to your clipboard.
